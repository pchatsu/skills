# 配色

AIが生成するUIが最も失敗しやすいのが配色である。とりあえず青を選ぶ。純粋な黒を使う。紫からシアンへのグラデーションを引く。アクセントカラーをページの30%に貼り付ける。これらをすべて避ける。

## 原則

- **OKLCHのみを使う。** 知覚的に均一で、明度が予測可能で、色相がティント全体で一貫する。`hsl()` や `rgb()` は明るさについて嘘をつく。
- **アクセントは1色、多くても2色まで。** それ以外はすべてニュートラルにする。アクセントカラーはどの画面においても**3%以下**の面積に収める。
- **極端な値を使わない。** `#000` も `#fff` も使わない。常にパレットのアンカーとなる色相にわずかなクロマを乗せてティントする。
- **グレーにも色を乗せる。** アンカーの色相がオレンジならニュートラルは暖色寄りに、青なら寒色寄りにする。暖色アクセント＋寒色グレーの本文という組み合わせは、理由はわからなくても「なんとなくおかしい」と感じるページになる。

## パレットの構成

パレットは4つのレイヤーで構成する。

1. **Paper（紙面）** — 基礎となる面。ライトモードは `oklch(96–98% 0.005–0.015 <アンカー色相>)`、ダークモードは `oklch(12–16% 0.008–0.015 <アンカー色相>)`。
2. **Ink（インク）** — 本文の主要テキスト色。ライトモードは `oklch(16–22% 0.005–0.015 <アンカー色相>)`、ダークモードは `oklch(92–96% 0.005–0.01 <アンカー色相>)`。
3. **Neutrals（ニュートラル）** — PaperとInkの間を5〜9段階で埋める。各段階にアンカーのクロマを低い値（0.005–0.015）で乗せる。
4. **Accent（アクセント）** — 意味のあるクロマ（0.12–0.22）を持つ、彩度のある1色。リンク、アクティブ状態、ハイライト、フォーカスリングに使う。面積の数%を超える背景塗りには使わない。

例（暖色系オート色、色相80）:

```css
:root {
  --color-paper:    oklch(96%  0.012 80);
  --color-paper-2:  oklch(93%  0.014 80);
  --color-rule:     oklch(82%  0.010 80);
  --color-neutral:  oklch(56%  0.008 80);
  --color-muted:    oklch(40%  0.008 70);
  --color-ink:      oklch(18%  0.010 60);
  --color-accent:   oklch(63%  0.21  50);       /* シグナルオレンジ */
  --color-focus:    oklch(55%  0.19  55);
}
```

例（ミッドナイト色、色相40）:

```css
:root {
  --color-paper:    oklch(14%  0.008 40);
  --color-paper-2:  oklch(18%  0.010 40);
  --color-rule:     oklch(30%  0.008 40);
  --color-neutral:  oklch(58%  0.008 40);
  --color-muted:    oklch(72%  0.006 40);
  --color-ink:      oklch(94%  0.006 80);
  --color-accent:   oklch(72%  0.18  50);       /* シグナルオレンジ */
  --color-focus:    oklch(70%  0.19  55);
}
```

## コントラスト

可能であればAPCAでコントラストを確認する。難しければWCAG 2.1の比率を使う。

| コンテンツ | 最低ライン | 目標値 |
| --- | --- | --- |
| 本文テキスト | 4.5:1 | 7:1 |
| 大きな文字（18.66px以上のbold、または24px以上） | 3:1 | 4.5:1 |
| UIコンポーネントの境界線 | 3:1 | 4.5:1 |
| プレースホルダー / ヘルパーテキスト | 4.5:1 | 4.5:1 |

出荷前にブラウザのdevtoolsにある色覚特性エミュレーターで確認する。

## ダークモードのレシピ

- Paper: 明度12〜18%（`#000` にしない）。
- Ink: 明度92〜96%（`#fff` にしない）。
- 本文のfont-weightは50単位下げる（400 → 350）。暗い背景に明るい文字を置くと視覚的な太さが増すため、その分を相殺する。
- アクセント: クロマを0.02〜0.04下げ、明度を5〜10%上げる。
- 高低差（elevation）: 上位の面は暗くではなく*明るく*する。1段階につき明度を約3%足す。
- モード間で色相を変えない。アンカー色相は固定し、明度とクロマだけを動かす。

## 禁則事項

- **純粋な `#000000`** はどこにも使わない。代わりに `oklch(16% 0.01 <色相>)` 程度にする。
- **純粋な `#ffffff`** を基礎の面に使わない。ティントしたPaperを使う。
- **フラットなグレー**（`oklch(L 0 H)` でクロマがゼロ）は避ける。最低でも0.005は乗せる。
- **紫からシアン、紫から青、オレンジからピンクへのグラデーション。** すべてのLLMが選びがちなので避ける。
- **アクセントを背景塗りとして使う**場合は、どの画面でも面積の5%を超えない。
- **色付き背景の上にグレーの文字。** 常に色あせて見える。
- **赤緑の組み合わせだけを意味の伝達手段にする。** アイコンやパターンを併用する。
- **アルファ透明度だけで色を定義する。** 名前付きトークンであれば不透明にする。透明度はオーバーレイやシャドウの*修飾子*であり、パレットそのものではない。
- **3色グラデーション。** 2色ストップに留める。3色目は虚飾にすぎない。

## アクセントカラーの使い方

アクセントはハイライターであり、色の面ではない。次のような場面で使う。

- アクティブなナビ項目を示す。
- フォーカスリングを描く。
- ホバー時にリンクに下線を引く。
- 重要な用語や強調テキストの下線・文字色として使う。
- 見出しの脇に小さな四角を置き、視線の起点にする。

大きな図形やブロックを塗りつぶしたり、セクション全体をアクセント色にしたり、装飾的なグラデーションに使ったりしない。「もっと使いたい」と思ったら、それは使いすぎのサインである。使用量は少なく保つ。
