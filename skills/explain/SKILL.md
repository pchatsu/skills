# Explain

指定されたコード変更について、要点を把握できる説明を作成してください。

背景:
- 解決したい課題、変更する理由など具体的な背景を説明する。
- 変更差分の場合、必要に応じて今回の変更に関連する既存のシステムについて説明する。

内容：
- 本質を説明することに重点を置く。
- コンポーネント感のデータフロー、通信を示すシステム図を必要に応じて作成する。フローはアニメーションなどで流れをわかりやすく説明する。
- 具体的なサンプル、図やグラフは積極的に利用する。
- 理解度をテストする5つの質問を作成する。難易度は中程度で意地悪な質問は避ける。

出力形式：
- CSSとJavascriptを含む単一のHTML
- セクションヘッダと目次を含む
- ASCII図は使用しない
- コードブロックには、`<pre>` タグを使用する
- トップレベルの構造にタブを使用しない
- ファイルはコードリポジトリ外のローカルフォルダに保存
